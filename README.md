# ♟️ Minerva Chess Engine

> *"A sabedoria não é um destino — é o próprio movimento."*

**Minerva** é um motor de xadrez rudimentar escrito em Java, desenvolvido como um projeto pessoal de aprendizado.

O nome vem de **Minerva**, deusa romana da sabedoria, das artes e das estratégias de guerra — uma escolha deliberada para um jogo que é, antes de tudo, sobre pensar.

## Sobre

O objetivo é entender como um motor de xadrez funciona, implementando as ideias à medida que elas fazem sentido. O projeto não tem requisitos fixos nem escopo fechado — ele cresce conforme o conhecimento cresce.

TCCs e artigos acadêmicos que embasam o desenvolvimento estão em [`/Material`](./Material).
